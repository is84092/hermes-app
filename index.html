Hermes Personal Assistant

This is a private, single-user tool. It uses the Gmail API only to send and read email on behalf of its owner (for example, delivering personal summary reports to the owner's own inbox).

It is not offered to the public and has no other users.

本應用程式為個人自用工具，僅用於代表擁有者寄送與讀取自己的電子郵件（例如寄送個人摘要報告），不對外提供服務。
